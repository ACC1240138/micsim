## Fixed harmonization decisions

1. **States and labels.** `ts_ST <- c("N0","FD","C1","C2","C3","C4")`, destinations `ts_Y <- c("NC","C1","C2","C3","C4")`; sex `Men`/`Women`. Crosswalk from v2: ND_unknown -> N0, cat1-cat4 -> C1-C4, Male/Female -> Men/Women. Categories by grams/day with the EPS cutpoints: C1 g < lo; C2 lo <= g < hi; C3 hi <= g <= 100; C4 g > 100; lo = 20 (women) / 40 (men), hi = 40 / 60.
2. **Population.** Respondents (`Entrevistado == 1`), age 18-65 at origin; destination age unrestricted. Age groups `18-29, 30-44, 45-59, 60-65` (EPS `ep_age`).
3. **Intervals.** `ts_periods <- c("R7_R8","R8_R9","R9_R10","R10_R11")`. Round months: R7 2023-04, R8 2023-12, R9 2024-04, R10 2024-11, R11 2025-04 (R11 unverified). Elapsed months m: 8, 4, 7, 5; `years = m/12`; `min_years = (m-1)/12`, `max_years = (m+1)/12`.
4. **Link compatibility (EPS rule).** A destination record is a valid link only if same sex and `age_to - age_from` is within `[floor(min_years), ceiling(max_years)]`. Incompatible records are treated as not linked (destination state NA) and counted in `link_audit.csv`. The same rule, with the months between the two rounds, applies to history links.
5. **History (FD).** At wave w a non-drinker is FD if any earlier wave of the same person, compatible by rule 4 with its own elapsed months, reported current drinking; otherwise N0. Past-only; never uses later waves. R7 non-drinkers are always N0.
6. **Current drinking and quantity.** `current = e3a1 > 1`. Drinks/day = days_per_week x typical_drinks / 7 with days_per_week = c(0, 0.5*7/30.4375, 3*7/30.4375, 2.5, 5.5)[e3a1] and typical_drinks = c(1, 3.5, 5.5, 8, 10)[e3a2]; grams = 12 x drinks/day (primary), 15.7 (sensitivity, every main model including A), upper band 16 drinks (point-estimate sensitivity). Keep raw codes in memory. C4 is unreachable at 12 g with the 10-drink top value (maximum 94.29 g/day): disclose.
7. **Education (EPS completion-based levels).** Levels exactly as EPS: `"Primary completed or less"`, `"Secondary completed or less"`, `"Tertiary completed or higher"`, plus `"Missing"`; `edu_num` 0/1/2 (0 when missing) and `edu_missing` 0/1. Rule (primary, lenient): b4a 1-4 -> level 1; b4a 5 (Media CH): b4b >= 4 -> level 2 else level 1; b4a 6 (Media TP): b4b >= 4 -> level 2 else level 1; b4a 7 (Superior tecnica): b4b >= 2 -> level 3 else level 2; b4a 8 (Universitaria): b4b >= 4 -> level 3 else level 2; b4a 9 -> level 3; b4a 10 or NA -> Missing. If `b1 == 1` (currently attending) the current level is not completed (b4b is the current grade): media in progress -> level 1; superior in progress -> level 2; postgrado in progress -> level 3. Sensitivities: strict thresholds (tecnica >= 3, universitaria >= 5) and the v2 reached-level rule (b4a 1-4 -> 1, 5-6 -> 2, 7-9 -> 3). Export `education_rule_audit.csv` (per wave: b4a x b4b -> level counts) and EPS-style `education_mapping_changed` counts.
8. **Typical-quantity signal (harmonized HED auxiliary).** `signal = 1` if current drinker and e3a2 in {3,4,5} (band lower bound >= 5, above both sex thresholds), 0 if current drinker with e3a2 in {1,2}, NA if not current. Women in band 2 (3-4 drinks) are 0 with an `ambiguous` flag. The 6+ item (`hed6 = 1` if e3a3 in 2:5) is TSM-only, reported separately (`hed6_item_by_category.csv`), not a predictor of the main outcome models.
9. **Weights and IPW (EPS three stages).** `wbase` = origin `Fact_Exp`. Stage a (origin classification observed) is constant 1 in TSM; stage b: `linked ~ period + state0 + sex + age_group + edu_num + edu_missing + lg0 + signal0f + hed6_0 + phq2 + region + employment + partnered + owner + log_history + after_R7` (quasibinomial, QR-pivoted); stage c (destination classification observed given linked) is constant 1. Probability floor 0.02, weights clipped at the training 1st/99th percentiles within period, each period's mass fixed at its observed complete-pair count (`ts_period_mass`). IPW, clipping and shrinkage are learned inside training folds and replicates.
10. **Outcome models (EPS set and formula).** Common formula `~ state0 + sex * age_group + period + lg0 + edu_num + edu_missing` (`lg0 = log(grams0)` for drinkers, 0 otherwise). Models: `A` (shrunken matrix global -> period -> sex -> sex x age, k tuned on `ts_kgrid` in 3 inner person folds), `A_education`, `Multinomial`, `Gamma`, `Lognormal`, `Ordinal_two_part`, `NonPO_two_part`, `Ordinal_single`, `JRT_reference` (`~ state0*age_group + state0*sex + sex*age_group + period`), `Gamma_no_education`, `Gamma_education_interaction`, `Lognormal_education_interaction`, plus TSM-only `Lognormal_tsm_extras` (common formula + `signal0f + hed6_0 + phq2 + region + employment + log_history`). Main models: A, Multinomial, Gamma, Lognormal, Ordinal_two_part, Ordinal_single, JRT_reference. Weight-scale invariance check as EPS.
11. **Validation.** 5 person folds x 3 repeats, seeds `1240138 + rep`; weighted log loss (floor 1e-8), Brier, accuracy; repeated scores and means; paired contrasts as EPS but with person clusters (`survey::svydesign(ids = ~id, weights = ~wcv)`), interval basis string "person-cluster Taylor; conditional on fitted OOF predictions"; include every pair among the main models (every JRT contrast included). Calibration by destination category (A, Gamma, Lognormal, Ordinal_two_part, Ordinal_single, Multinomial) and **by origin cell** (`calibration_by_origin_cell.csv`: origin x sex x age group x destination: n_origin, observed, predicted, absolute and relative difference, `sparse = n_origin < 30`).
12. **Matrices.** `ep_matrices` port: by period x sex x age group (main models), pooled by sex x age group, pooled "All", and by education level (point estimates). Structural zeros and unsupported rows as EPS. Engine coefficients for Gamma and Lognormal.
13. **Uncertainty.** No PSU/strata exist: primary = whole-person bootstrap, `ts_B = 1000`, seed `1240138 + 600`, IPW refitted, same multiplier for all pairs of a person; models in replicates: A, Gamma, Lognormal, Ordinal_single, and the annual generator for A, Gamma, Lognormal. Intervals with the EPS `ep_interval(method = "person")` logic (bootstrap SD, logit scale, bounded limits at 0/1); unsupported rows reported, never fabricated. `bootstrap_stability.csv` for 100/250/500/1000 and a replicate audit; any failed replicate stops inference. The v2 pair bootstrap is dropped.
14. **Annual layer.** EPS continuous-time generator (`ep_Q`, `ep_expm`, `ep_annual`) fitted jointly to the four TSM intervals with their `years`; penalty 5e-5, starts 0.02/0.05/0.1, gradient check; bootstrap CI; sensitivity grid (penalties 1e-5, 5e-5, 2e-4 x starts) for A, Gamma and Lognormal with a `model` column. Labelled exploratory, as in EPS.
15. **Cross-source check with EPS (aggregates only).** Read `__andres_control/eps_markov_outputs/annual_pooled_matrices_design_CI.csv` (A, Gamma, Lognormal annual matrices with JKn intervals) and `transition_matrices_design_CI.csv`. (a) Table and figure of annual staying probabilities TSM vs EPS by model with both intervals. (b) EPS -> TSM projection: recover a generator from each EPS annual matrix (same optimizer, target delta = 1), project to the TSM interval lengths and score the TSM observed pairs by origin state (weighted log loss and Brier, pooled and by period), next to the TSM models' own held-out scores. (c) TSM -> EPS projection: project the TSM generator to 3.671 and 4.03 years and compare with the EPS observed-origin pooled matrices (model A rows aggregated by `n_origin`). Report as external consistency, not validation.
16. **Merged C3+C4 variant.** Destinations NC, C1, C2, C3plus (and origin C3plus); refit A, Lognormal and Ordinal_single, CV scores, pooled matrices and the annual layer; side-by-side table with the six-state results.
17. **Other sensitivities.** Conversion 15.7 g for every main model (`conversion_sensitivity.csv` as EPS plus full pooled matrices in `transition_matrices_15_7g.csv`); upper band 16 drinks; base weights vs base + IPW (`weight_refit_sensitivity.csv`); education strict and reached rules (CV scores for A and Lognormal, pooled matrices); interval transport (train on three intervals, test on the fourth, person-disjoint); earlier-history check (origin w-1 state and grams for pairs with a compatible earlier wave; Gamma and Gamma_education_interaction); Chapman-Kolmogorov descriptive diagnostic on three-wave cohorts (collapsed NC / C1-C2 / C3-C4, bootstrap CI); rank matching vs panel (EPS `ep_rank` by sex x age group).

## Deviations and additions recorded during implementation (2026-10-19)

- **Decision 5 (history) is implemented as the EPS chain, not as direct links to every earlier wave.** The flag that drinking was observed travels from each interview to the person's next observed interview when that link is compatible by rule 4 with its own months. With approximate round dates, direct non-adjacent bounds contradicted chains of compatible adjacent links in 16 linked pairs and broke the N0/FD transition map. The direct flag (`prior_use_direct`) and the v2 any-history flag are exported in `abstention_history_audit.csv`.
- **Rule 4 as contracted removes 287 of the 4,175 present destinations (6.9%)**, almost all age increments of two years or more within intervals of 4-8 months. The adversarial review (2026-10-19) showed that `a3` is a household-roster age that interviewers correct sporadically (codebook label), that the excluded pairs are the same roster members (identifier, region and education agreement equal to the retained pairs) and that they start drinking about twice as often as the retained ones (selection on the outcome). **The primary bounds are therefore the EPS bounds widened by one year on both sides (`ts_link_tolerance = 1`, keeping 4,121 pairs)**, applied to destination links and to the history chain; the strict EPS bounds are the sensitivity (`link_audit_strict_bounds.csv`, `link_bounds_sensitivity.csv`, `link_bounds_sensitivity_cv.csv`, `link_bounds_pooled_matrices.csv`). This is the one confirmed default that was changed on evidence; the user can revert it by setting the constant to 0.
- The cross-check projections are saved in separate files because their columns differ: `eps_crosscheck_projection_eps_to_tsm.csv`, `eps_crosscheck_projection_eps_matrices.csv`, `eps_crosscheck_projection_tsm_to_eps.csv`, `eps_crosscheck_projection_tsm_to_eps_summary.csv` (replacing the single `eps_crosscheck_projection`).
- Education and upper-band sensitivities export point summaries and pooled matrices (`education_sensitivity.csv`, `education_sensitivity_pooled_matrices.csv`, `education_sensitivity_cv.csv`, `upper_band_sensitivity.csv`, `upper_band_pooled_matrices.csv`).
- Transport: stage-b IPW is period-specific, so the held-out period's weights are fitted on the training persons' rows of that period (the EPS person-fold mechanism); only the outcome models are restricted to the other three periods, and held-out rows take the period level of the training period closest in elapsed months (`proxy_period`).
- IPW stage b is one pooled quasibinomial fit with period as a factor (decision 9), with per-period caps and masses.
- The Chapman-Kolmogorov diagnostic uses a person bootstrap with seed `ts_seed + 700`; `ts_score_contrasts` also contrasts `Lognormal_tsm_extras` with `Lognormal`.
- After the dry run (2026-10-19): the shrinkage grid is `c(10, 30, 100, 300, 1000, 3000, 10000)` because the tuned value reached the EPS boundary (1000); annual rows whose origin state has no observed pairs (C4 at 12 g) are reported as `unobserved origin` with blank estimates instead of penalty-driven values, and `n_origin`/`support` columns were added to `annual_pooled_matrices_person_CI.csv` and `eps_crosscheck_annual.csv`; the Chapman-Kolmogorov bootstrap treats an unobserved collapsed origin as zero mass instead of propagating NA; `eps_crosscheck_projection_eps_to_tsm.csv` carries an in-sample origin-only TSM baseline (`TSM_origin_only_insample`) as the like-for-like reference for the EPS projection; the two-class branch of the class-probability port names its columns explicitly (a latent bug in `eps_markov_core.R`, which never meets two observed classes).
- Extra CSVs beyond item 18: `link_bounds_sensitivity.csv`, `link_bounds_sensitivity_cv.csv`, `link_bounds_pooled_matrices.csv`, `education_sensitivity_cv.csv`, `education_sensitivity_pooled_matrices.csv`, `upper_band_pooled_matrices.csv`, the four `eps_crosscheck_projection_*.csv` files, `merged_C3plus_cv_scores.csv`, `merged_C3plus_pooled_matrices.csv`, `merged_C3plus_annual.csv`.
- Gamma amount models fall back to the version 2 BFGS minimiser of the same objective when IRLS does not converge (one CV fold under the widened link rule); the fallback is counted in `fit_warnings.csv`.
- Review-driven additions (2026-10-19): `fd_tenure_audit.csv`, `annual_interval_fits.csv`, `link_audit_strict_bounds.csv`, the `FD_eps_rule` column, four weighting scenarios with ESS in `weight_refit_sensitivity.csv`, collapsed-destination TSM-to-EPS projection with a `comparable` flag and two summaries, `n_origin`/`support`/`comparable` columns in `eps_crosscheck_annual.csv`, support flags in `merged_C3plus_annual.csv`, the verifier's repeat check and N0/C1 summary lines, and `_quarto.yml` excluding `*_dry.ipynb`.
- Dry-run hooks: the environment variables `TSM_B` and `TSM_REPEATS` shrink the bootstrap and the CV repeats; the verifier requires the defaults (1000 and 3).
